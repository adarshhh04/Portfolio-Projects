# 💰 Personal Finance Dashboard - Power BI


## 📌 Overview

This Power BI dashboard provides an interactive visualization of personal finance data over four years (2018-2021). It tracks **income**, **expenses**, and **savings**, helping users understand where their money goes and how they save.

---

## 📁 Files Included

- `Finance_Dashboard.pbix` - Power BI Dashboard File
- `financial_data.csv` - Raw Dataset
- `README.md` - This file
- `Documentation.md` - Detailed explanation

---

## 📊 Key Features

- **Summary Cards** for Total Income, Expenses, Savings %, Expense %
- **Trend Analysis** (MoM Income, Savings %, Expense %)
- **Bar Charts**: Categorized Spending and Saving
- **Detailed Table** for yearly breakdowns
- **Time Filters**: by Year and Month

---

## 💡 Insights

- Highest Spending: House Rent
- Top Saving Category: Mutual Funds
- Expense Percentage: ~78.41%
